# My First Website 🌐
A nostalgic look back at my very first web project, created when I was 16 years old in high school. This project marks the beginning of my journey into software development.

## ✨ Overview
*   **Purpose**: High school web design assignment.
*   **Style**: Classic, hand-coded static site.
*   **Vibe**: Simple, clean, and the foundation of everything I've built since.

## 🛠️ Tech Stack
*   **HTML5**: Structure and semantic layout.
*   **CSS3**: Basic styling, positioning, and colors.
